# 📝 Personal Blogger

A full-stack blogging platform built using the **MERN stack** that allows users to create, manage, and view blog posts through a modern web interface.

## 🚀 About the Project

Personal Blogger is a full-stack web application developed to provide a simple and user-friendly platform for publishing and managing blog content.

The project follows a client-server architecture:

- **Frontend:** React.js
- **Backend:** Node.js + Express.js
- **Database:** MongoDB
- **API Communication:** REST APIs

The application demonstrates practical implementation of frontend development, backend API development, database integration, and full-stack application architecture.

---

## ✨ Features

### 👤 User Features

- Create and publish blog posts
- View available blog posts
- Read individual blog posts
- Manage blog content
- Responsive and user-friendly interface

### 📝 Blog Management

- Create blog posts
- Update blog posts
- Delete blog posts
- View complete blog content
- Store blog data in MongoDB

### 🔗 Backend

- RESTful API architecture
- Express.js server
- MongoDB database integration
- API-based communication between frontend and backend
- Environment variable configuration
